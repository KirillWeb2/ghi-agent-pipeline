# Руководство по вкладу в проект

## Как подготовить код к коммиту

### 1. Установите зависимости

```bash
npm install
```

### 2. Запустите проверки в указанном порядке

```bash
# Автоисправьте ошибки линтера
npm run lint:fix

# Переформатируйте код
npm run format

# Убедитесь, что проект собирается
npm run build
```

Если после этих команд ошибок нет — код готов к коммиту.

### 3. Если остались ошибки

#### `npm run lint` всё ещё выдаёт ошибки
- Откройте файл с ошибкой
- Прочитайте описание ошибки в консоли
- Исправьте вручную (часто это неиспользуемые переменные или логические ошибки)

#### `npm run format:check` выдаёт ошибки форматирования
- Запустите `npm run format` заново
- Проверьте, что файлы изменены корректно

#### `npm run build` падает с ошибкой сборки
- Это означает, что в коде есть синтаксические ошибки или неверные импорты
- Откройте файл, указанный в ошибке
- Исправьте синтаксис вручную
- Запустите `npm run build` заново

## Правила кодирования

- **Минимум импортов**: избегайте неиспользуемых импортов
- **JSX правила**: используйте React Hooks вместо классовых компонентов где возможно
- **Форматирование**: доверьте Prettier, не форматируйте вручную
- **Стиль имён**: `camelCase` для функций/переменных, `PascalCase` для компонентов

## Полезные команды

```bash
# Запустить dev-сервер
npm run dev

# Только проверить линтер (без исправлений)
npm run lint

# Только проверить форматирование (без изменений)
npm run format:check

# Собрать production-версию
npm run build

# Проверить production-версию локально
npm run preview
```
