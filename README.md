# Vite + React App

Минималистичный Vite + React проект с настроенной проверкой качества кода через ESLint.

## Установка

```bash
npm install
```

## Скрипты

### Разработка
- `npm run dev` — запуск dev-сервера (http://localhost:5173)
- `npm run preview` — предпросмотр собранного приложения

### Качество кода
- `npm run lint` — проверка кода ESLint (только вывод ошибок)
- `npm run lint:fix` — автоисправление ESLint ошибок
- `npm run build` — сборка для production

## Workflow проверки кода перед коммитом

Рекомендуемый порядок команд перед коммитом:

```bash
npm run lint:fix   # автоисправление стиля и простых ошибок
npm run lint       # финальная проверка на остальные нарушения
npm run build      # проверка, что проект собирается
```

Если все команды завершились успешно (exit code 0) — код готов к коммиту.

## Интерпретация ошибок

### Ошибки ESLint (`npm run lint`)
- **Синтаксические / style ошибки**: неиспользуемые переменные, пропущены точки с запятой, неверная индентация и т.д.
- **React-специфичные**: отсутствие зависимостей в хуках, неправильное использование props.
- **Решение**: прочитать текст ошибки, исправить вручную или запустить `npm run lint:fix`.

### Ошибки сборки (`npm run build`)
- **Синтаксические ошибки JavaScript**: неправильный импорт, отсутствующие модули, циклические зависимости.
- **Конфликты с конфигом Vite**: неподдерживаемые форматы файлов в src/, нарушение правил ESM.
- **Решение**: изучить полный текст ошибки (обычно указан файл и строка), исправить источник проблемы.

## Конфигурация

- **ESLint** (`.eslintrc.json`): preset для React с eslint-config-prettier (без отдельного Prettier).
- **Prettier** (`.prettierrc.json`): настройки форматирования (используются ESLint правилами через конфиг prettier).

## CI/CD

В CI конвейер следует добавить:

```bash
npm ci
npm run lint
npm run build
```

Любой exit code ≠ 0 приведёт к падению пайпа.
