# Vite + React App

Это шаблон проекта React с Vite, ESLint и базовой конфигурацией качества кода.

## Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Разработка

```bash
npm run dev
```

Отворит приложение на `http://localhost:5173`.

### Проверка качества кода

#### Локально перед коммитом

Запусти команды в порядке:

1. **Проверка и исправление стиля кода:**
   ```bash
   npm run lint:fix
   ```
   Исправляет автоматически исправляемые ошибки (пробелы, кавычки, точки с запятой и т.д.).

2. **Проверка без исправления:**
   ```bash
   npm run lint
   ```
   Выведет список ошибок, которые нельзя исправить автоматически. Завершится с ненулевым кодом, если есть ошибки.

3. **Сборка проекта:**
   ```bash
   npm run build
   ```
   Убедиться, что проект собирается без ошибок (Vite).

#### В CI/CD

В пайплайне добавь:

```bash
npm run lint && npm run build
```

Если прекомит-хук: запусти `npm run lint:fix` перед коммитом, затем `npm run lint` для финальной проверки.

## Понимание ошибок

### Ошибка линтера (ESLint)

**Вывод:**
```
src/App.jsx
  5:10  error  'unused' is assigned a value but never used  no-unused-vars
```

**Причина:** Код нарушает правило качества (неиспользуемая переменная, неправильный синтаксис и т.д.).

**Решение:**
- Запусти `npm run lint:fix` — многие исправляются автоматически (форматирование, пробелы).
- Оставшиеся ошибки исправь вручную (удали неиспользуемые переменные, добавь пропущенные dependencies в hooks).

### Ошибка сборки Vite

**Вывод:**
```
error during build:
Error: Cannot find module './missing.js'
```

**Причина:** Ошибка при бандлировании (импорт несуществующего файла, синтаксическая ошибка в коде и т.д.).

**Решение:** Прочитай стек трейс, исправь путь импорта или синтаксис.

## Конфигурация

### ESLint (`eslint.config.js`)

Использует:
- **`@eslint/js`** — базовые рекомендуемые правила.
- **`eslint-plugin-react`** — правила для React (JSX, пропсы).
- **`eslint-plugin-react-hooks`** — проверка Rules of Hooks (useEffect, useState).
- **`eslint-config-prettier`** — отключает правила, конфликтующие с форматированием (пробелы, кавычки).

Полный список правил см. в `eslint.config.js`.

## Дополнительно

Для лучшего опыта в IDE:
- **VS Code:** Установи расширение [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint), чтобы видеть ошибки прямо в редакторе.
- **Настройка автосохранения:** В `.vscode/settings.json` добавь `"editor.codeActionsOnSave": { "source.fixAll.eslint": true }` для автоисправления при сохранении.
